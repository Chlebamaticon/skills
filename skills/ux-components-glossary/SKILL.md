# UX Components Glossary

Shared **atomic** vocabulary for UI **composition**: **atoms**, **molecules**, and **organisms**, with catalog purposes from [UX Components](https://www.ux-components.com/components/atomic).

## Steps

1. Load [GLOSSARY.md](GLOSSARY.md) before naming or leveling a new component.
2. Pick the level that matches the component’s job — indivisible block (**atom**), simple reusable pattern (**molecule**), or self-contained section (**organism**).
3. Prefer an existing catalog name and purpose when the component is the same pattern; leave unclassified catalog entries unclassified rather than inventing a level.
4. When defining or composing a matched catalog component, load its `components/{id}.md` for use / avoid / states / anatomy / related.

**Done when:** the new component has a chosen level, a name aligned with the glossary when a match exists, detail from the matching `components/{id}.md` applied when one exists, and any composition of smaller pieces uses the same vocabulary.

## Levels (inline)

| Level | Purpose |
| --- | --- |
| **Atoms** | Basic, indivisible UI elements — the smallest functional building blocks. |
| **Molecules** | Simple combinations of atoms that form distinct, reusable UI patterns. |
| **Organisms** | Complex, self-contained components built from atoms and molecules. |

Full component tables and the unclassified appendix live in [GLOSSARY.md](GLOSSARY.md).
