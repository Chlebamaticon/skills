# Card

**Level:** Molecule  
**Category:** Layout

A self-contained, rectangular surface grouping related content and actions about a single subject.

## When to use
- Product or item listings in grids and feeds
- Dashboard widgets with metrics or charts
- User profiles, team member listings
- Blog post previews and article feeds
- Settings panels grouping related options

## When to avoid
- When items don't need visual separation — use a simple list instead
- Nesting cards inside cards more than one level deep
- Cards with too much content — if it's very long, use a page or section instead
- Making every piece of content a card — reserve cards for truly grouped units
- Using shadow to convey interactivity without an actual interactive trigger

## States
- **Default** — The card is displayed at rest with standard background and border.
- **Hover** — When the card is interactive, a hover state (border color shift or background change) signals clickability.
- **Selected** — The card is in a chosen or checked state — used in selection grids or multi-select lists.
- **Loading** — A skeleton version of the card is shown while content is being fetched.
- **Empty** — The card has no data to display — an empty state message or illustration fills the body.
