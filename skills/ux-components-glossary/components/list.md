# List

**Level:** Molecule  
**Category:** Data Display

A vertical arrangement of related content items with consistent spacing and structure.

## When to use
- Settings menus with labelled options
- Contact or user lists with avatars
- Notification or activity feeds
- Navigation menus in sidebars
- Search results with previews

## When to avoid
- For tabular data with multiple columns — use a Table or Data Table
- For very short option sets — use Radio Group or Select
- For grid-based visual browsing — use Card grids
- When items have complex multi-column layouts

## States
- **Default** — Items displayed in their normal state.
- **Hover** — An item is highlighted on mouse hover.
- **Selected** — One or more items are marked as chosen.
- **Focused** — An item has keyboard focus.
- **Empty** — No items to display; empty state is shown.
- **Loading** — Placeholder skeletons are shown while data loads.

## Anatomy
- **List Container** — Wraps all items with consistent spacing and optional dividers.
- **List Item** — An individual row containing content.
- **Leading Element** — Optional icon, avatar, or checkbox before the text.
- **Primary Text** — The main label or title of the item.
- **Secondary Text** — Optional supporting description text.
- **Trailing Element** — Optional action, badge, or metadata on the right.
