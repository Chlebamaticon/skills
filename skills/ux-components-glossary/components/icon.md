# Icon

**Level:** Atom  
**Category:** Content

A symbolic graphic element used for visual communication, labeling, and wayfinding.

## When to use
- Button labels and navigation items
- Status indicators (success, error, warning, info)
- Form field prefixes and suffixes
- Empty state illustrations
- Wayfinding and category identification

## When to avoid
- As the only means of communication — always provide a text alternative
- When the meaning is ambiguous without context
- At very small sizes where detail is lost
- When a text label alone would be clearer and more direct

## States
- **Default** — The icon is displayed at its standard size and color.
- **Hover** — The icon changes color or opacity on mouse hover.
- **Active** — The icon is pressed or currently selected.
- **Disabled** — The icon is dimmed and non-interactive.
