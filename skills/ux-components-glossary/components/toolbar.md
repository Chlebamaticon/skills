# Toolbar

**Level:** Organism  
**Category:** Action

A horizontal container that groups related actions, controls, and tools into a compact bar.

## When to use
- Rich text and code editors
- Data table action bars (filter, sort, export)
- Image and design tool palettes
- Email and messaging action bars
- Dashboard widget controls

## When to avoid
- When there are only 1-2 actions — use standalone buttons
- For primary navigation — use a Navigation Menu or Tabs
- For page-level actions — use a page header with action buttons
- When actions are contextual to a selection — use a Context Menu

## States
- **Default** — All tools are visible and interactive.
- **Overflow** — Some items are hidden behind a more menu due to limited width.
- **Focused** — A tool item has keyboard focus.
- **Disabled** — The entire toolbar or individual items are non-interactive.
