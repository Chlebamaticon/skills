# Chip

**Level:** Atom  
**Category:** Data Display

A compact, interactive element representing an input, attribute, or action in a condensed form.

## When to use
- Displaying selected filters that can be removed
- Email or user input fields with tokenized entries
- Category or tag selectors in filter bars
- Multi-select values shown as removable pills
- Action chips triggering contextual operations

## When to avoid
- For static, non-interactive labels — use a Badge or Tag
- For navigation — use Tabs or Buttons
- When there's only one option — use a Toggle or Checkbox
- For long-form content — chips should be concise

## States
- **Default** — Chip is displayed in its unselected state.
- **Selected** — Chip is visually marked as active or chosen.
- **Hover** — Chip or its remove button is highlighted.
- **Focused** — Chip has keyboard focus.
- **Disabled** — Chip is non-interactive.
