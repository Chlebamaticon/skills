# Timeline

**Level:** Molecule  
**Category:** Data Display

A chronological display of events or activities arranged along a vertical or horizontal line.

## When to use
- Activity logs and audit trails
- Order tracking and shipment progress
- Project milestones and roadmaps
- User onboarding step indicators
- Version history and changelog displays

## When to avoid
- For step-by-step processes with user input — use a Stepper
- For non-chronological data — use a List or Card layout
- When there are only 2–3 items — the timeline structure adds unnecessary complexity
- For real-time streaming data — consider a live feed or notification pattern

## States
- **Default** — All events displayed in chronological order.
- **Active** — The current or most recent event is highlighted.
- **Completed** — Past events are visually marked as done.
- **Pending** — Future events are dimmed or dashed.
- **Loading** — Events are being fetched; skeleton placeholders shown.
