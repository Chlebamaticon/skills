## Body

Durable agent outcomes live in a **memory-bank** under two roots: repo-centric `<project>/.memory/` (default writes) and global `$HOME/.memory/` (cross-repo agreements only). Categories: `decisions`, `patterns`, `practices`, `domains`, `sessions`. Agents use **remember** when outcomes crystallise and **recall** when starting work that may inherit prior entries. Structure changes update `skills/memory-bank/GLOSSARY.md` in the same change.
